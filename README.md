# API Users, аналог работы с СУБД(2)
#### Что бы это работало установи node, после скачай файл Node.js, открой терминал и в нем перейди в эту папку, после напиши npm init, нажимай Enter пока не появится подтверждения создания файла package.json, подтверди и вставь в него
#### {
####   "name": "00",
####   "version": "1.0.0",
####   "description": "",
####   "scripts": {
####     "start": "nodemon ./server.js"
####   },
####   "author": "Makar Star",
####   "license": "ISC",
####   "devDependencies": {
####     "nodemon": "^3.1.14"
####   },
####   "dependencies": {
####     "body-parser": "^2.2.2",
####     "express": "^5.2.1",
####     "express-handlebars": "^9.0.1"
####   }
#### } и нажми Ctrl + S, после в терминале введи npm i и жди установки, после установки введи node server.js и пользуйся
### В верхней части страницы будет ссылки на сайты перейдя на который ты сможешь взаимодействовать с массивом пользователей, удалить, добавлять, изменять, вывести по id и вывести всех, это функции из предыдущей версии который работают также
